# 대리머니 — 개인정보 처리방침

**시행일자:** 2026년 10월 1일

김지태(이하 "개발자")는 모바일 애플리케이션 **"대리머니 (DaeriMoney)"**(이하 "앱") 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 등 관련 법령을 준수합니다.

## 1. 처리하는 개인정보 항목 및 수집 방법

앱은 별도의 회원가입·로그인이 필요 없으며, 운행 기록·정산 기능을 위해 이용자가 직접 입력한 정보와 서비스 이용 과정에서 자동으로 생성되는 정보가 있습니다.

### 1-1. 이용자가 직접 입력하는 정보 (기기 내에만 저장)

| 구분 | 항목 |
|---|---|
| 콜(운행) 기록 | 시작 시각, 소요 시간, 출발지·도착지(이용자가 입력한 텍스트), 요금, 수수료, 보험료, 순수익, 결제수단, 메모, 콜 플랫폼 |
| 비용 기록 | 발생 일시, 금액, 메모, 비용 카테고리 |
| 사용자 설정 | 콜 플랫폼 목록, 비용 카테고리 목록, 화면 테마(라이트/다크/시스템) |

이 정보는 **기기 내 SwiftData(로컬 저장소)에만 저장**되며, **개발자의 서버나 외부로 전송되지 않습니다**. iCloud(CloudKit) 동기화는 사용하지 않으므로, 이용자가 입력한 운행·비용 데이터는 해당 기기를 벗어나지 않습니다. 앱은 위치 정보, 연락처, 사진, 카메라, 마이크 등 기기 권한을 요청하지 않습니다. 출발지·도착지는 이용자가 직접 입력한 텍스트일 뿐이며 GPS 등으로 수집되지 않습니다.

### 1-2. 문의하기 기능 이용 시 전송되는 정보

더보기의 "문의" 기능으로 의견을 제출하면, 아래 정보가 개발자가 운영하는 Google Firebase Firestore(클라우드 데이터베이스)에 저장됩니다. 이 기능은 이용자가 제출 버튼을 누른 경우에만 동작합니다.

| 항목 | 설명 |
|---|---|
| 문의 내용 | 이용자가 직접 작성한 텍스트 |
| 기기 모델 | 예: iPhone17,1 |
| iOS 버전 | 예: 27.0 |
| 앱 버전 | 예: 1.0 |
| 제출 일시 | 서버 기록 시각 |

이름·이메일·전화번호 등 이용자를 직접 식별하는 정보는 자동으로 수집하지 않습니다. **문의 내용에 이름, 연락처, 계좌번호 등 개인정보나 민감한 정보를 적지 않도록 주의해 주십시오.** 답변을 원하시는 경우에는 아래 개인정보 보호책임자 이메일로 직접 연락해 주십시오.

### 1-3. 자동 수집 정보 (제3자 SDK가 수집)

아래 정보는 **개발자가 직접 수집·보관하는 것이 아니라, 앱에 통합된 Google Firebase SDK가 각자의 목적에 따라 자동으로 수집·처리**합니다. 개발자는 이 데이터를 개인을 식별할 수 있는 형태로 직접 저장하지 않으며, 집계·익명화된 결과만 확인합니다.

| 구분 | 항목 | 수집 주체 |
|---|---|---|
| 기기 식별자 | IDFV 및 앱 인스턴스 ID | Firebase Analytics, Firebase Crashlytics |
| 기기·환경 | OS 종류·버전, 기기 모델, 앱 버전, 언어·지역 설정 | Firebase Analytics, Firebase Crashlytics |
| 위치 | IP 주소 기반 대략적 위치(국가/지역 수준) | Firebase Analytics |
| 이용 기록 | 화면 조회(홈·달력·더보기·콜 입력 등 화면 이름), 앱 실행 등 기본 이벤트 | Firebase Analytics |
| 진단·충돌 데이터 | 비정상 종료(충돌) 로그, 오류 기록(발생 위치·오류 설명), 성능 지표 | Firebase Crashlytics |

- 콜·비용의 금액, 메모, 출발지·도착지 등 **이용자가 입력한 내용은 분석·진단 데이터에 포함되지 않습니다.**
- 앱은 광고를 표시하지 않으며, 광고 식별자(IDFA)를 수집하거나 이용자를 추적하지 않습니다.
- 분석(Firebase Analytics) 및 충돌 진단(Firebase Crashlytics) 데이터는 **개발(디버그) 빌드에서는 수집되지 않으며**, App Store에 배포되는 출시 빌드에서만 수집됩니다.

## 2. 개인정보의 처리 목적

- 앱의 핵심 기능 제공: 콜·비용 기록, 일별·월별 순이익 정산, 달력 조회
- 이용자 문의 접수 및 응대, 서비스 개선 (Firebase Firestore)
- 서비스 품질 개선 및 이용 통계 분석 (Firebase Analytics)
- 비정상 종료(충돌) 진단 및 오류 수정 (Firebase Crashlytics)

## 3. 개인정보의 보유 및 이용 기간

| 항목 | 보유 기간 |
|---|---|
| 이용자가 입력한 콜·비용·설정 데이터 | 기기 내, 이용자가 삭제하거나 앱을 삭제할 때까지 |
| 문의 내용 및 기기·앱 정보 | 문의 처리 및 서비스 개선 목적이 달성될 때까지 보관 후 삭제 (이용자가 삭제를 요청하면 지체 없이 삭제) |
| 분석 데이터(이벤트 로그) | 수집일로부터 최대 14개월 |
| 충돌·진단 데이터 | Google Firebase Crashlytics 정책에 따름(통상 최대 90일) |

## 4. 개인정보의 제3자 제공 및 처리 위탁

앱은 다음 수탁업체에 일부 정보의 처리를 위탁합니다. **이용자가 입력한 콜·비용 데이터는 어떠한 제3자에게도 제공되지 않습니다.**

| 수탁업체 | 위탁 업무 | 위탁 항목 |
|---|---|---|
| Google LLC (Firebase Analytics, Crashlytics) | 앱 사용 분석, 충돌·진단 로그 수집 | 기기 식별자, 이벤트 로그, 충돌 로그, IP |
| Google LLC (Firebase Firestore) | 문의 내용 저장·관리 | 문의 내용, 기기 모델, iOS 버전, 앱 버전, 제출 일시 |

수탁업체는 한국 외 국가(주로 미국)에 위치한 서버에서 데이터를 처리할 수 있습니다. 이용자가 이 처리를 원하지 않는 경우 문의하기 기능을 사용하지 않으실 수 있으며, 앱의 다른 기능은 문의 기능과 무관하게 이용할 수 있습니다.

## 5. 정보주체의 권리 및 행사 방법

이용자는 다음 권리를 언제든지 행사할 수 있습니다.

- **본인이 입력한 콜·비용 데이터 열람·수정·삭제**: 앱 내에서 직접 수정·삭제 가능
- **앱 전체 데이터 삭제**: 앱 삭제 시 기기에 저장된 모든 콜·비용·설정 데이터가 제거됩니다
- **분석·진단 데이터 수집 거부**: 출시 빌드에서 Firebase Analytics·Crashlytics는 기본적으로 동작합니다. 수집 중단 또는 이미 수집된 정보의 **열람·삭제·처리정지**는 아래 연락처로 요청해 주십시오.
- **문의 내용 열람·삭제**: 제출한 문의 내용(가능하면 대략적인 제출 일시 포함)을 아래 연락처로 알려 주시면 확인 후 삭제합니다. 문의 데이터에는 이용자 식별자가 포함되지 않으므로, 본인 확인을 위해 제출 내용·시기 등의 추가 정보를 요청드릴 수 있습니다.

정당한 요청은 지체 없이 처리합니다.

## 6. 개인정보의 안전성 확보 조치

- 이용자가 입력한 콜·비용 데이터는 외부 서버에 전송되지 않으며, 기기 내에서만 처리됩니다
- iCloud(CloudKit) 동기화를 사용하지 않으므로, 입력 데이터가 클라우드에 동기화되지 않습니다
- Firebase SDK와의 통신은 HTTPS(TLS) 암호화 채널을 사용합니다
- 문의 데이터가 저장되는 Firestore는 접근 권한 규칙을 설정하여 외부에서 임의로 열람할 수 없도록 관리합니다
- 수집되는 식별자는 익명·가명 처리된 형태로만 활용됩니다
