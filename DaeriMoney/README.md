# 대리머니 — 개인정보 처리방침

iOS 앱 **대리머니 (DaeriMoney)** 의 개인정보 처리방침 모음입니다. 대리운전 기사가 콜(운행)과 비용을 기록하고 순이익을 정산하는 운행 기록·정산 앱입니다.

각 언어 폴더의 루트 URL이 **App Store Connect 등록용 안정 URL**입니다.

## 언어 선택 / Language

| 언어 | Language | URL (App Store Connect 등록용) |
|---|---|---|
| 한국어 | Korean | [`ko/`](./ko/) |

## 적용 법령 기준

- `ko/` — 한국 「개인정보 보호법(PIPA)」 + 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」

앱이 한국어 단일 로케일(대한민국 대리운전 기사 대상)이라 한국어 정책만 제공합니다.

## 앱 데이터 특징

- **콜·비용 기록은 기기 내 SwiftData에만 저장**되며 외부 서버로 전송되지 않음. iCloud(CloudKit) 동기화 사용 안 함
- 회원가입·로그인·위치·사진·연락처 등 기기 권한 요청 없음
- **Firebase Analytics·Crashlytics** 사용 — 출시 빌드에서만 화면 조회 이벤트와 충돌·오류 로그 수집 (이용자 입력 내용 미포함)
- **Firebase Firestore**는 더보기 "문의" 제출 시에만 사용 — 문의 내용, 기기 모델, iOS·앱 버전, 제출 일시 저장
- 광고(AdMob)·광고 식별자(IDFA)·추적 동의 없음, 인앱 구매 없음
